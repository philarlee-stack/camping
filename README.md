# 🏕 숲속 캠핑 — 온라인 감성 캠핑

집 안에서 즐기는 3D 힐링 캠핑 웹 프로그램입니다.
실제 시간에 맞춰 변하는 하늘, 비·눈·안개, 모닥불 불멍, 사운드 믹서, 그리고 최대 4명이 함께하는 캠핑 사이트까지.

- **기술**: React · Three.js(React Three Fiber) · Web Audio API · GSAP · Zustand · Socket.io
- **상세 설계/로드맵/에셋 가이드**: [`docs/DESIGN.md`](docs/DESIGN.md)

---

## 1. 빠른 시작

### 준비물
- Node.js **18 이상** (https://nodejs.org)
- 최신 Chrome / Edge / Safari / Firefox (WebGL 지원)

### 혼자서 즐기기 (가장 간단)
```bash
npm install
npm run dev
```
브라우저에서 **http://localhost:5173** 을 엽니다.

### 친구와 함께 즐기기 (멀티플레이)
터미널 두 개를 열어 각각 실행합니다.
```bash
# 터미널 1: 멀티플레이 서버 (포트 3001)
npm run server

# 터미널 2: 화면 (포트 5173)
npm run dev
```
또는 한 번에 배포 모드로 실행:
```bash
npm start        # 빌드 후 http://localhost:3001 에서 화면 + 서버 모두 제공
```

> 같은 와이파이의 친구는 `http://내PC주소:3001` (배포 모드)로 접속하면 됩니다.
> 인터넷 너머 친구와 하려면 서버를 공개 서버(VPS 등)에 올려야 합니다. ([docs/DESIGN.md](docs/DESIGN.md) 배포 체크리스트 참고)

## 2. 사용 방법

### 시작
1. 첫 화면에서 **캠핑장 입장**을 누릅니다. (브라우저 정책상 클릭해야 소리가 켜집니다. 🎧 권장)
2. 마우스 드래그로 둘러보고, 휠(또는 핀치)로 확대/축소합니다.

### 장비를 직접 클릭하세요
| 대상 | 동작 |
|---|---|
| 🔥 **화로대** | 불 붙이기 / 끄기 (불이 켜져야 타닥타닥 소리가 납니다) |
| 🏮 **랜턴** | 켜기 / 끄기 (색온도는 패널 슬라이더로 조절) |
| ✨ **알전구** | 켜기 / 끄기 |
| 🪑 **의자** | 앉아서 불멍 시점으로 이동 (다시 클릭하면 일어나기) |
| ⛺ **텐트** | 텐트 안으로 들어가기 (다시 클릭하면 나오기) |
| ☕ **드립 세트** (주방 테이블) | 커피 내리기 — 물 붓는 소리와 김이 올라옵니다 |
| 🍡 **마시멜로 봉지** (주방 테이블) | 불이 켜져 있을 때 클릭 → 불 위에서 굽기. 5초쯤에 노릇하게, 오래 두면 타요. **꼬치를 클릭하면 먹습니다** |

### 왼쪽 패널
패널 맨 위의 **◀ 숨기기** 버튼으로 사이드바를 접을 수 있고, 접으면 왼쪽 위에 **☰ 메뉴** 버튼이 나타나 다시 열 수 있습니다. (`H` 키는 모든 UI를 한 번에 숨김)

| 섹션 | 기능 |
|---|---|
| 🎥 카메라 | 전체 / 불멍 / 텐트 안 시점 전환 |
| 🌅 시간 | **실시간**(내 컴퓨터 시각) 또는 직접 조절 (일출·낮·노을·밤 바로가기) |
| 🌦 날씨·계절 | 맑음 / 비 / 안개 / 눈, 봄·여름·가을·겨울, 바람 세기 (바람이 세면 낙엽·꽃잎이 흩날려요) |
| ⛺ 캠핑 사이트 | 인원 1~4인, 텐트(소형 돔 / 대형 티피), 장비 토글, 랜턴 색온도 |
| 🎧 사운드 믹서 | 전체 + 모닥불·새·풀벌레·비·바람·파도 개별 볼륨 |
| 👥 함께 캠핑 | 닉네임·사이트 이름을 입력하고 입장 → 감정 표현 |

### 사운드 믹서 팁
- **자동 믹스**가 켜져 있으면 낮엔 새소리, 밤엔 풀벌레, 비가 오면 빗소리가 알아서 커집니다.
- 슬라이더를 직접 만지면 자동 믹스가 꺼지고 내 설정이 유지됩니다. (체크박스로 다시 켤 수 있어요)
- 모닥불 소리는 불이 꺼져 있으면 자동으로 조용해집니다.
- 다른 채널을 모두 0으로 두고 모닥불만 올리면 타닥거리는 불 소리만 들립니다. (배경의 낮은 웅웅거림은 제거했고, 1% 미만의 볼륨은 완전 무음 처리됩니다.)

### 멀티플레이 (최대 4명)
1. `npm run server`가 실행 중이어야 합니다.
2. **👥 함께 캠핑** → 닉네임과 **같은 사이트 이름**을 입력 → **입장하기**
3. 이미 4명이 있으면 입장이 거절됩니다.
4. 불·랜턴·알전구·날씨·계절은 **방 전체가 공유**됩니다. (마지막으로 바꾼 사람 기준)
5. 의자에 앉으면 다른 사람 화면에도 내가 앉아 있습니다.
6. 감정 표현: 👋 손 흔들기 · 🙏 합장 인사 · 🔥 불멍하기 · 🎧 음악 듣기 (4.5초 후 자동 해제)

### 단축키
| 키 | 동작 |
|---|---|
| `1` / `Esc` | 전체 시점 |
| `2` | 불멍 시점 |
| `3` | 텐트 시점 |
| `F` | 불 켜기/끄기 |
| `L` | 랜턴 켜기/끄기 |
| `H` | UI 숨기기/보이기 (몰입 모드) |

### 시점별 조작
- **전체**: 드래그 = 회전, 휠 = 확대/축소
- **불멍 / 텐트 안**: 제자리에서 드래그하면 고개를 돌립니다.

## 3. 소리를 더 실감 나게 (선택)

기본 소리는 브라우저에서 **합성**되어 별도 파일 없이 동작합니다.
실제 녹음 음원을 쓰고 싶다면 `public/audio/`에 아래 이름으로 파일을 넣으세요. (mp3 / ogg / wav)

```
public/audio/fire.mp3  birds.mp3  crickets.mp3  rain.mp3  wind.mp3  waves.mp3
```
- 30~60초 길이의 루프 음원 권장, CC0/로열티프리 음원 사용
- 파일이 있는 채널만 실제 음원으로 바뀌고, 나머지는 합성음을 그대로 씁니다.
- 출처는 `public/audio/CREDITS.txt`에 기록하세요.

## 4. 프로젝트 구조

```
camp-in-the-woods/
├─ README.md               ← 지금 보는 사용 설명서
├─ docs/DESIGN.md          ← 기획·기술 설계서·로드맵·에셋 전략
├─ index.html, vite.config.js, package.json
├─ public/audio/           ← (선택) 실제 음원 넣는 곳
├─ server/index.js         ← Socket.io 멀티플레이 서버 (최대 4인 룸)
└─ src/
   ├─ App.jsx, main.jsx, store.js, CameraRig.jsx
   ├─ audio/   AudioEngine.js(믹서·합성·효과음), AudioBridge.jsx(자동 앰비언스)
   ├─ nature/  timeOfDay.js(태양·하늘 계산), NatureEngine.jsx(하늘·광원·날씨), Terrain.jsx(지면·호수·숲)
   ├─ camp/    Campfire, Tent, Furniture, Kitchen, CampLights, Avatar, Players, CampSite, layout
   ├─ net/     multiplayer.js (클라이언트)
   └─ ui/      UI.jsx, ui.css
```

## 5. 커스터마이징

| 하고 싶은 일 | 수정 위치 |
|---|---|
| 일출/일몰 시각(계절별) | `src/nature/timeOfDay.js` → `SEASON_DAYLIGHT` |

| 의자 배치/반경 | `src/camp/layout.js` → `R`, `ANGLES` |
| 자동 믹스 규칙 | `src/audio/AudioBridge.jsx` |
| 이모트 추가 | `src/camp/Avatar.jsx`(`EMOTES`, `switch`) + `server/index.js`(`EMOTES`) |
| 서버 포트 | 환경변수 `PORT` (기본 3001), 개발 프록시는 `vite.config.js` |
| 허용 도메인 | 환경변수 `CORS_ORIGIN` |

## 6. 문제 해결

| 증상 | 해결 |
|---|---|
| 소리가 안 나요 | "캠핑장 입장"을 눌렀는지, 탭이 음소거가 아닌지, 믹서 볼륨(전체/채널)을 확인하세요. 모닥불 소리는 불을 켜야 납니다. |
| 화면이 버벅여요 | 브라우저 하드웨어 가속 켜기. 그래도 느리면 `NatureEngine.jsx`의 비/눈 파티클 수를 절반으로 줄이세요. |
| "멀티플레이 서버에 연결할 수 없어요" | `npm run server`가 실행 중인지 확인하세요. (개발 모드는 3001 포트 사용) |
| "이미 4명이 모두 찼어요" | 다른 사이트 이름으로 입장하세요. |
| 친구가 내 PC에 접속이 안 돼요 | 방화벽에서 3001 포트를 허용하고 `npm start`(배포 모드)로 실행하세요. |
| `npm install` 오류 | Node.js 18 이상인지 `node -v`로 확인하세요. |

## 7. 알려진 한계
- 장비·아바타는 코드로 만든 로우폴리 형상입니다. 실제 glTF 모델로 교체하는 방법은 `docs/DESIGN.md` 5장을 참고하세요.
- 시간은 실시간 연동이지만 실제 날씨 정보는 연동되지 않습니다. (수동 전환)
- 멀티플레이는 의자 기반의 간단한 동기화이며, 서버 재시작 시 방 정보가 초기화됩니다.
